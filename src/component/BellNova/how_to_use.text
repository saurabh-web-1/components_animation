## 1. COMPONENT OVERVIEW

**BellNova** is an animated notification bell built with:

* React
* Tailwind CSS
* Framer Motion

Features included:

* Animated notification bell
* Unread notification count
* Pulsing unread indicator
* Bell shake animation
* Expanding sound waves
* Animated notification panel
* Individual notification read state
* Mark all as read
* Notification count animation
* Responsive notification layout

---

## 3. CHANGE NOTIFICATIONS

All notification data is stored in:

```jsx
const notifications = [
  {
    id: 1,
    icon: "⚡",
    title: "New component added",
    text: "Animated search component is now live.",
    time: "2 min ago",
  },
];
```

Add another notification:

```jsx
{
  id: 4,
  icon: "✓",
  title: "New update",
  text: "Your profile has been updated.",
  time: "5 min ago",
}
```

Each notification should have:

```jsx
id
icon
title
text
time
```

## 8. UNREAD COUNT

Unread notifications are calculated with:

```jsx
const unreadCount = notifications.length - read.length;
```

The count automatically updates when notifications are marked as read.

---

## 9. MARK NOTIFICATION AS READ

Each notification uses:

```jsx
onClick={() => markAsRead(item.id)}
```

The function prevents duplicate IDs:

```jsx
const markAsRead = (id) => {
  setRead((prev) =>
    prev.includes(id) ? prev : [...prev, id]
  );
};
```

Clicking a notification changes it to the read state.

---

## 10. MARK ALL AS READ

The button uses:

```jsx
const markAllRead = () => {
  setRead(notifications.map((item) => item.id));
};
```

This marks every notification as read.

## 17. SOUND WAVES

Sound waves appear only when the notification panel is open.

The component creates three waves:

```jsx
[0, 1, 2].map((i) => ...)
```

Wave delay:

```jsx
delay: i * 0.12
```

Change `0.12` to control the spacing between waves.

## 22. PANEL ANIMATION

Opening animation:

```jsx
initial={{
  opacity: 0,
  y: -15,
  scale: 0.94,
}}
```

Final state:

```jsx
animate={{
  opacity: 1,
  y: 0,
  scale: 1,
}}
```

Exit animation:

```jsx
exit={{
  opacity: 0,
  y: -10,
  scale: 0.95,
}}
```

Adjust these values to customize the panel motion.

## 28. OPEN / CLOSE STATE

The panel is controlled by:

```jsx
const [open, setOpen] = useState(false);
```

Toggle:

```jsx
setOpen((prev) => !prev)
```

Close:

```jsx
setOpen(false)
```

---

## 29. READ STATE

Read notification IDs are stored in:

```jsx
const [read, setRead] = useState([]);
```

Example:

```jsx
[1, 3]
```

means notifications `1` and `3` are read.

## 30. CONNECT TO AN API

Currently notifications are static:

```jsx
const notifications = [...]
```

For a real application, replace this with API data.

Expected notification structure:

```js
{
  id,
  icon,
  title,
  text,
  time
}
```

You can load the notifications using `useEffect()` and an API request.

## 33. IMPORTANT

BellNova currently uses local React state.

The notifications and read status will reset when the component is refreshed.

For production use, connect notifications and read status to your backend or persistent storage.
