## 1. COMPONENT OVERVIEW

**BellNova** is an animated notification component built with:

* HTML
* CSS
* Vanilla JavaScript
* Inline SVG

Features:

* Animated notification bell
* Unread notification counter
* Bell ringing animation
* Expanding sound waves
* Notification dropdown panel
* Read/unread notification states
* Mark all as read
* Outside-click closing
* Responsive mobile layout

No external JavaScript library is required.

---

## 2. CHANGE NOTIFICATIONS

Notifications are written directly inside the HTML:

```html
<div class="notification-item unread" data-index="1">
```

Each notification contains:

```html
<strong>New component added</strong>
<p>Animated search component is now live.</p>
<small>2 min ago</small>
```

Change these values to create your own notifications.

---

## 3. ADD A NEW NOTIFICATION

Copy an existing notification:

```html
<div class="notification-item unread" data-index="4">

  <div class="notification-avatar">
    <span>!</span>
  </div>

  <div class="notification-content">
    <strong>New update</strong>
    <p>A new update is available.</p>
    <small>Just now</small>
  </div>

  <span class="unread-dot"></span>

</div>
```

Also update the JavaScript initial count:

```js
let unreadCount = 4;
```

And the HTML counter:

```html
<span class="notification-count" id="notificationCount">4</span>
```

## 10. BELL RING ANIMATION

The bell animation is controlled by:

```css
.bell-button.ringing .bell-icon svg {
  animation: bellRing 0.8s cubic-bezier(.36,.07,.19,.97);
}
```

The rotation sequence is inside:

```css
@keyframes bellRing
```

Example values:

```css
12% {
  transform: rotate(16deg);
}

24% {
  transform: rotate(-14deg);
}
```

Increase the degree values for a stronger ring.

---

## 13. COUNTER PULSE

The badge uses:

```css
animation: notificationPulse 1.8s infinite;
```

Change `1.8s` to control the pulse speed.

The pulse size is controlled here:

```css
@keyframes notificationPulse {
  50% {
    box-shadow:
      0 0 0 7px rgba(255,59,48,0);
  }
}
```

## 14. SOUND WAVES

Three sound waves are created:

```html
<span class="wave wave-1"></span>
<span class="wave wave-2"></span>
<span class="wave wave-3"></span>
```

They animate when the bell receives the `ringing` class:

```css
.bell-button.ringing .wave {
  animation: waveExpand 0.9s ease-out;
}
```

## 23. READ NOTIFICATION

When a notification is read, JavaScript adds:

```js
item.classList.remove("unread");
item.classList.add("read");
```

Read styling:

```css
.notification-item.read {
  opacity: 0.55;
}
```

Change `0.55` to control the faded appearance.

## 25. MARK ALL AS READ

Button:

```html
<button class="mark-read" id="markRead">
  Mark all as read
</button>
```

Its JavaScript changes every notification to:

```js
item.classList.remove("unread");
item.classList.add("read");
```

Then:

```js
unreadCount = 0;
updateCounter();
```

---

## 26. COUNTER UPDATE

The `updateCounter()` function updates:

* Notification count
* Counter visibility
* Notification status text

When there are no unread notifications:

```js
statusElement.textContent =
  "You're all caught up";
```

Otherwise:

```js
statusElement.textContent =
  `${unreadCount} unread notification${
    unreadCount > 1 ? "s" : ""
  }`;
```

## 27. OPEN / CLOSE PANEL

Bell click toggles:

```js
isOpen = !isOpen;
```

When open:

```js
notificationPanel.classList.add("open");
```

When closed:

```js
notificationPanel.classList.remove("open");
```

---

## 28. CLOSE BUTTON

The close button uses:

```js
closeButton.addEventListener("click", () => {
  notificationPanel.classList.remove("open");
  isOpen = false;
});
```

---

## 29. OUTSIDE CLICK

The component automatically closes when the user clicks outside the bell or panel:

```js
document.addEventListener("click", (event) => {
  if (
    isOpen &&
    !notificationPanel.contains(event.target) &&
    !bellButton.contains(event.target)
  ) {
    notificationPanel.classList.remove("open");
    isOpen = false;
  }
});
```

## 30. MOBILE RESPONSIVE

At screens below `480px`:

```css
@media (max-width: 480px) {
  .notification-panel {
    width: calc(100vw - 30px);
    right: -80px;
  }
}
```

Change `-80px` if you need to reposition the panel on mobile.

## 33. IMPORTANT

The current component uses static HTML notifications and JavaScript state.

The read/unread state exists only while the page is open. Refreshing the page resets the notifications to their initial state.

For a production notification system, the notification data and read status can be connected to an API or backend.
