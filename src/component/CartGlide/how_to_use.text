## 1. COMPONENT OVERVIEW

`CartGlide` is an animated shopping cart component built with:

* React
* Tailwind CSS
* Framer Motion

It includes:

* Product grid
* Add-to-cart animation
* Flying product animation
* Cart quantity management
* Remove product
* Cart preview bar
* Animated cart drawer
* Placement/delivery options
* Order note textarea
* Subtotal calculation
* Checkout button

The main component is:

```jsx
export default function CartGlide() {
```

## 7. ADD TO CART

The main function is:

```jsx
const addToCart = (product) => {
```

When the user clicks `+ Add`, this function runs:

```jsx
onClick={() => addToCart(product)}
```

The function:

1. Finds the clicked product.
2. Finds the cart position.
3. Calculates the starting position.
4. Calculates the cart position.
5. Creates the flying animation.
6. Adds the product to the cart.
7. Updates the quantity if the product already exists.
8. Triggers the cart pulse animation.

## 10. CART QUANTITY

The quantity is calculated using:

```jsx
const totalItems = useMemo(
  () => cart.reduce((sum, item) => sum + item.quantity, 0),
  [cart]
);
```

The subtotal is calculated using:

```jsx
const subtotal = useMemo(
  () =>
    cart.reduce(
      (sum, item) => sum + item.price * item.quantity,
      0
    ),
  [cart]
);
```

This means the subtotal automatically updates when:

* A product is added
* Quantity increases
* Quantity decreases
* A product is removed

---

## 11. CHANGE QUANTITY

Quantity is controlled by:

```jsx
const changeQuantity = (id, amount) => {
```

Increase:

```jsx
changeQuantity(item.id, 1)
```

Decrease:

```jsx
changeQuantity(item.id, -1)
```

The quantity cannot go below `0`.

When it reaches `0`, the product is automatically removed from the cart.

## 12. REMOVE PRODUCT

Products can be completely removed using:

```jsx
const removeItem = (id) => {
  setCart((previous) =>
    previous.filter((item) => item.id !== id)
  );
};
```

The `Remove` button calls:

```jsx
removeItem(item.id)
```

## 13. CART PREVIEW BAR

The cart preview is fixed at the bottom:

```jsx
fixed bottom-6
```

It displays:

* Product thumbnails
* Number of items
* Subtotal
* View cart button

Only the first three product thumbnails are shown:

```jsx
cart.slice(0, 3)
```

If more products exist, it displays:

```jsx
+{cart.length - 3}
```

## 15. OPEN CART DRAWER

Clicking:

```jsx
View cart
```

runs:

```jsx
setCartOpen(true)
```

The cart drawer is displayed when:

```jsx
cartOpen
```

is `true`.

Clicking outside the drawer closes it:

```jsx
onClick={() => setCartOpen(false)}
```

Clicking inside the drawer does not close it because of:

```jsx
event.stopPropagation()
```

---

## 16. CART DRAWER ANIMATION

The drawer starts with:

```jsx
y: 80,
opacity: 0,
scale: 0.97
```

and animates to:

```jsx
y: 0,
opacity: 1,
scale: 1
```

It uses a spring animation:

```jsx
transition={{
  type: "spring",
  stiffness: 350,
  damping: 30,
}}
```

You can modify `stiffness` and `damping` to change the feel of the drawer animation.

## 17. PLACEMENT / DELIVERY OPTIONS

The component contains three options:

```jsx
Home
Store
Schedule
```

The selected option is stored in:

```jsx
const [placement, setPlacement] = useState("home");
```

Each option changes the placement value:

```jsx
setPlacement("home")
setPlacement("store")
setPlacement("schedule")
```

You can add more options by creating another:

```jsx
<PlacementOption />
```

---

## 18. CUSTOMIZE DELIVERY OPTIONS

Each option contains:

```jsx
<PlacementOption

  subtitle="3–5 days"

```

Change:

```jsx
title
```

for the option name.

Change:

```jsx
subtitle
```

for the delivery information.
