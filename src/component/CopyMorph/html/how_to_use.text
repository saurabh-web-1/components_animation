# CopyFlip

CopyFlip is a lightweight **HTML, CSS, and JavaScript** copy-to-clipboard button with a smooth flip animation.

When the user clicks the button:

**Copy Code → ✓ Copied!**

The component includes a copy icon, animated check icon, text flip animation, success flash, hover effect, and clipboard fallback.

---

## 1. Requirements

CopyFlip does not require any library or framework.

You only need:

* HTML
* CSS
* JavaScript

No npm package is required.

---

## 2. File Structure

Create three files:

```text
CopyFlip/
├── index.html
├── style.css
└── script.js
```

## 4. Source Text

The text that will be copied is stored inside a hidden textarea.

```html
<textarea id="sourceText" hidden>
const message = 'Hello World';
</textarea>
```

Change the content to whatever you want the button to copy.

For example:

```html
<textarea id="sourceText" hidden>
npm install express
</textarea>
```

Now clicking the button copies:

```text
npm install express
```

---

## 5. JavaScript Setup

Connect the button and source text:

```javascript
const copyButton =
  document.getElementById("copyButton");

const buttonText =
  document.getElementById("buttonText");

const sourceText =
  document.getElementById("sourceText");
```

When the button is clicked, the `copyText()` function runs.

```javascript
copyButton.addEventListener(
  "click",
  copyText
);
```

---

## 6. Clipboard Function

CopyFlip first uses the modern Clipboard API:

```javascript
await navigator.clipboard.writeText(text);
```

For environments where the Clipboard API is unavailable, it automatically uses a textarea fallback with:

```javascript
document.execCommand("copy");
```

This gives the component a fallback copy mechanism.

## 9. Animation

The component has two visual states.

### Default

```text
[ Copy Icon ] Copy Code
```

### Copied

```text
[ ✓ ] Copied!
```

The copied state includes:

* Copy icon disappearing
* Check icon flipping in
* Text flip animation
* Cyan success color
* Light flash animation
* Smooth transition

---

## 10. Success State

After successful copying, JavaScript adds:

```javascript
copyButton.classList.add("copied");
```

This changes the button appearance.

The text changes to:

```javascript
buttonText.textContent = "Copied!";
```

After **1.6 seconds**, the button automatically returns to:

```text
Copy Code
```

---

## 11. Reset Behavior

The reset is handled with:

```javascript
resetTimer = setTimeout(
  resetButton,
  1600
);
```

The reset function removes:

```javascript
copied
text-flip
flash
```

and restores the original text.

---

## 15. Accessibility

The button uses:

```html
aria-label="Copy code"
```

The SVG icons use:

```html
aria-hidden="true"
```

This prevents decorative SVG icons from being unnecessarily announced by screen readers.

The button also uses:

```html
type="button"
```

so it will not submit a form accidentally.
