# CopyPulse

CopyPulse is an animated copy button that copies predefined text to the clipboard and provides a smooth visual confirmation when the copy action succeeds.

## Features

* One-click copy functionality
* Copy and success icon transition
* Animated checkmark
* `"Copy Code"` → `"Copied!"` text transition
* Automatically resets after 1.6 seconds
* Uses the modern Clipboard API when available
* Includes a fallback copy method for unsupported environments
* Works with plain HTML, CSS, and JavaScript
* No external JavaScript library required


## 3. Add the JavaScript

Include the JavaScript before the closing `</body>` tag:

```html
<script src="script.js"></script>
```

The JavaScript handles:

1. Button click
2. Clipboard copy
3. Success state
4. Checkmark animation
5. `"Copied!"` text
6. Automatic reset

---

## 4. Change the Text to Copy

Open `script.js` and find:

```javascript
const textToCopy = "const message = 'Hello World';";
```

Replace it with any text you want.

### Example

```javascript
const textToCopy = "npm install framer-motion";
```

Now clicking the button will copy:

```text
npm install framer-motion
```

## 5. Copy HTML Code

You can also copy a complete HTML snippet.

```javascript

  <h2>Hello World</h2>
```

The text will be copied exactly as defined.

## 8. Copy Dynamic Text

If you want to copy text from another element, you can use:

```javascript
const textToCopy =
  document.getElementById("myCode").textContent;
```

Example:

```html
<pre id="myCode">
const name = "Saurabh";
console.log(name);
</pre>
```

Then:

```javascript
const textToCopy =
  document.getElementById("myCode").textContent;
```

## 10. How the Animation Works

Initially:

```text
📋  Copy Code
```

After clicking:

```text
✓  Copied!
```

The checkmark uses:

```css
@keyframes copyCheck {
  0% {
    opacity: 0;
    transform: scale(0.4) rotate(-20deg);
  }

  60% {
    opacity: 1;
    transform: scale(1.2) rotate(5deg);
  }

  100% {
    opacity: 1;
    transform: scale(1) rotate(0);
  }
}
```

After `1600ms`, the component automatically returns to its initial state.

## Browser Support

CopyPulse first attempts to use:

```javascript
navigator.clipboard.writeText()
```

When that is unavailable, it falls back to:

```javascript
document.execCommand("copy")
```

This makes the component usable in a wider range of browser environments.
