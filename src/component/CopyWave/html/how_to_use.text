# CopyWave — How to Use

CopyWave is an animated copy button for HTML, CSS, and JavaScript projects. When the user clicks the button, it copies predefined text to the clipboard and displays three expanding wave rings with a checkmark success animation.

## Features

* One-click clipboard copy
* Three expanding wave animations
* Animated success checkmark
* `"Copy Code"` → `"Copied!"` transition
* Automatic reset after 1.6 seconds
* Modern Clipboard API support
* Fallback copy method
* No external JavaScript library required
* Works with standalone HTML/CSS/JS

---

## 1. Folder Structure

Create a folder named `CopyWave`:

```text
CopyWave/
├── index.html
├── style.css
└── script.js
```

---

```html
  <span id="waveThree" class="wave wave-three"></span>

  <span class="icon-wrapper">

    <svg
      id="copyIcon"
      viewBox="0 0 24 24"
      width="18"
      height="18"
      fill="none"
      stroke="currentColor"
      stroke-width="2"
      stroke-linecap="round"
      stroke-linejoin="round"
    >
      <rect
        width="14"

  </span>

  <span id="copyText" class="copy-text">

  </span>

```

---

## 3. Connect CSS

Inside the `<head>` of your HTML file:

```html
<link rel="stylesheet" href="style.css">
```

The CSS controls the button design, hover effect, success state, wave animation, and checkmark animation.

---

## 4. Connect JavaScript

Before the closing `</body>` tag:

```html
<script src="script.js"></script>
```

The JavaScript controls copying, state changes, animations, and reset behavior.

---

## 5. Change the Text to Copy

Open `script.js` and find:

```javascript
const textToCopy = "const message = 'Hello World';";
```

Replace it with the content you want to copy.

Example:

```javascript
const textToCopy = "npm install react";
```

Clicking the button now copies:

```text
npm install react
```

---

## 6. Copy HTML Code

You can copy HTML snippets:

```javascript
const textToCopy = `
<div class="card">
  <h2>Hello World</h2>
</div>
`;
```

The complete snippet will be copied to the clipboard.

## 7. Copy CSS Code

You can also use CopyWave for CSS:

```javascript
const textToCopy = `

  padding: 20px;
  border-radius: 12px;
}
`;
```

---

## 8. Copy JavaScript Code

Example:

```javascript
const textToCopy = `
const message = "Hello World";

console.log(message);
`;
```

---

## 9. Copy Dynamic Content

You can copy content from another HTML element.

Example:

```html
<pre id="code">
const name = "Saurabh";
console.log(name);
</pre>
```

Then use:

```javascript
const textToCopy =
  document.getElementById("code").textContent;
```

This allows CopyWave to work with dynamically displayed code.

---

## 10. How the Copy Process Works

When the user clicks the button, JavaScript first checks whether the browser supports the modern Clipboard API:

```javascript
navigator.clipboard.writeText(textToCopy);
```

If it is available, the text is copied using the Clipboard API.

If it is unavailable, CopyWave uses a fallback method:

```javascript
document.execCommand("copy");
```

This provides compatibility with environments where the modern Clipboard API cannot be used.

---

## 11. Initial State

When the component first loads, the button displays:

```text
📋 Copy Code
```

The three wave elements are present but invisible.

---

## 12. Success State

After a successful copy:

```text
✓ Copied!
```

The button changes to the success style.

The copy icon is replaced by the check icon.

The three wave animations start from the center of the button.

---

## 13. Wave Animation

CopyWave uses three separate wave elements.

### Wave 1

Starts immediately:

```text
Delay: 0s
```

### Wave 2

Starts slightly later:

```text
Delay: 0.15s
```

### Wave 3

Starts after Wave 2:

```text
Delay: 0.30s
```

All waves expand from:

```text
scale(1)
```

to:

```text
scale(8)
```

while their opacity decreases to zero.

This creates the ripple/wave effect.

---

## 14. Checkmark Animation

The checkmark uses four animation stages:

```text
scale(0.3) + rotate(-30°)
        ↓
scale(1.3) + rotate(8°)
        ↓
scale(0.9) + rotate(-3°)
        ↓
scale(1) + rotate(0°)
```

This gives the checkmark a small pop/bounce effect.

The animation duration is:

```text
0.45 seconds
```

---

## 15. Automatic Reset

After successful copying, the component stays in the success state for:

```text
1600ms
```

After that, it automatically returns to:

```text
📋 Copy Code
```

The success color is removed, the check icon is hidden, and the copy icon becomes visible again.

---

## 16. Button States

CopyWave has two main visual states.

### Normal

```text
Copy Code
```

Dark background with a white copy icon.

### Copied

```text
Copied!
```

Green success color with a checkmark and expanding waves.

Normal hover background:

```css
.copy-wave:hover {
  background: #171c29;
```

```css
  background: rgba(16, 185, 129, 0.1);
```

```css
  color: #34d399;
}
```

```javascript

  // reset

```

## Browser Compatibility

CopyWave first attempts to use:

```javascript
navigator.clipboard.writeText()
```

If the modern Clipboard API is unavailable, it uses:

```javascript
document.execCommand("copy")
```

No external JavaScript package is required.
