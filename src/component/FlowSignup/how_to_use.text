## 1. COMPONENT OVERVIEW

`FlowSignup` is an animated signup component built with:

- React
- Tailwind CSS
- Framer Motion
- Lucide React

It includes:

- Expandable signup card
- Name field
- Email field
- Password field
- Confirm password field
- Password visibility toggle
- Password strength indicator
- Terms checkbox
- Signup loading state
- Google button
- Apple button
- Animated floating orb
- Responsive layout

---

## 2. REQUIREMENTS

Install the required packages:

```bash
npm install framer-motion lucide-react
```

Make sure Tailwind CSS is configured in your React project.

## 4. BASIC USAGE

Import the component:

```jsx
import FlowSignup from "./components/FlowSignup";
```

Render it:

```jsx
<FlowSignup />
```

Example:

```jsx
function App() {
  return (
    <main className="min-h-screen flex items-center justify-center">
      <FlowSignup />
    </main>
  );
}

export default App;
```

## 13. HANDLE SIGNUP

Use the `onSubmit` prop to connect your API:

```jsx
const handleSignup = async (data) => {
  console.log(data);
};
```

Pass it:

```jsx
<FlowSignup onSubmit={handleSignup} />
```

The submitted data contains:

```js
{
  name,
  email,
  password,
  confirmPassword,
  terms
}
```

---

## 14. CONNECT YOUR API

Example:

```jsx
const handleSignup = async (data) => {
  const response = await fetch("/api/signup", {
    method: "POST",
    headers: {
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });

  const result = await response.json();

  console.log(result);
};
```

The component waits for the `onSubmit` promise before ending its loading state.

---

## 15. PASSWORD VALIDATION

The component checks whether:

```js
password !== confirmPassword
```

If passwords do not match, submission is stopped.

The message displayed is:

```text
Passwords do not match.
```

Change this text directly in the JSX.

---

## 16. PASSWORD STRENGTH

Password strength is calculated from length:

```text
0 = Empty
1 = Less than 6 characters
2 = Less than 10 characters
3 = 10+ characters
```

You can change these values inside:

```jsx
const passwordStrength = ...
```

For example, create stricter password levels by modifying the length conditions.

---

## 17. PASSWORD VISIBILITY

The eye button toggles between:

## 40. LOADING STATE

When submitting, the component shows:

```text
Creating account...
```

with a spinner.

The form fields and buttons become disabled while loading.

The default demo submission waits:

```js
1400
```

milliseconds when no `onSubmit` prop is provided.

---

## 41. CHANGE DEMO LOADING TIME

Find:

```js
setTimeout(resolve, 1400)
```

Faster:

```js
setTimeout(resolve, 800)
```

Slower:

```js
setTimeout(resolve, 2000)
```

For production, use your actual API response instead of the demo delay.

---

## 42. IMPORTANT

The component itself does not create a user account or connect to a database.

Use `onSubmit` to connect it to your backend authentication API.

Google and Apple buttons are currently UI buttons and require your own authentication integration.

```jsx
      trigger="click"
      showSocial={true}
      showTerms={true}
      compactText="Sign up"
      primaryText="Create account"
      onSubmit={handleSignup}
    />
  );
}

export default App;
```
