# ANIMATED SHARE BUTTON — COMPONENT GUIDE

**Component:** AnimatedShareButton
**Type:** React + Tailwind CSS + Framer Motion
**File:** `AnimatedShareButton.jsx`

---

## 1. REQUIREMENTS

Make sure your React project has Tailwind CSS and Framer Motion installed.

```bash
npm install tailwindcss @tailwindcss/vite
npm install framer-motion
```

The component uses:

* `useState`
* Framer Motion
* `AnimatePresence`
* Browser Clipboard API

---

## 2. ADD THE COMPONENT TO YOUR PROJECT

Create a file such as:

```text
src/components/AnimatedShareButton.jsx
```

Paste the component code into that file.

---

## 3. IMPORT THE COMPONENT

In the page where you want to use it:

```jsx
import AnimatedShareButton from "./components/AnimatedShareButton";
```

If your folder structure is different, update the import path accordingly.

---

## 4. USE THE COMPONENT

Render the component like this:

```jsx
function App() {
  return (
    <div>
      <AnimatedShareButton />
    </div>
  );
}

export default App;
```

## 5. HOW THE SHARE BUTTON WORKS

The component has three visual states:

### Normal

* Displays the Share icon.
* Shows `Share` text.
* Displays a small animated arrow.
* Button responds to hover and click interactions.

### Sending

After clicking the button:

* The current page URL is copied to the clipboard.
* The button enters the sending state.
* The share icon transforms into a flying paper plane.
* The paper plane flies upward and outward.
* Motion trails appear behind the plane.
* Small particles are generated.
* The button glow becomes visible.
* Text changes to `Sending...`.

The URL is copied using:

```js
await navigator.clipboard.writeText(window.location.href);
```

---

### Shared

After the animation completes:

* The paper plane disappears.
* A check mark appears.
* A success flash animation plays.
* Text changes to `Shared`.
* The success state automatically resets after a short delay.

The component controls these states using:

```js
const [sending, setSending] = useState(false);
const [shared, setShared] = useState(false);
```

---

## 6. SHARE ANIMATION

The main animation is designed around a flying paper plane.

During the sending state, the plane moves:

```js
x: [0, 3, 75, 135],
y: [0, 4, -25, -82],
rotate: [-8, -8, -3, 8],
scale: [0.65, 0.85, 1, 0.75],
opacity: [0, 1, 1, 0]
```

This creates the effect of the paper plane launching from the button and flying away.

The animation lasts approximately:

```js
duration: 1.15
```

---

## 7. SHARE URL

By default, the component shares the current page URL:

```js
window.location.href
```

The URL is copied using the browser Clipboard API:

```js
await navigator.clipboard.writeText(window.location.href);
```

This means the same component can be placed on different pages without changing the URL manually.

---

## 8. CHANGE WHAT GETS SHARED

If you want to share a custom URL instead of the current page, replace:

```js
await navigator.clipboard.writeText(window.location.href);
```

with:

```js
await navigator.clipboard.writeText("https://example.com");
```

You can also make the URL dynamic:

```js
const shareUrl = "https://example.com/product/123";

await navigator.clipboard.writeText(shareUrl);
```

## 12. SUCCESS ANIMATION

When sharing finishes, a success check mark appears.

The check mark uses an animated SVG path:

```js
initial={{ pathLength: 0 }}
animate={{ pathLength: 1 }}
```

This creates a drawing-style check animation.

The success state also creates a quick border flash around the button.

## 15. CUSTOMIZE THE GLOW

The button has a glow effect that becomes visible while sending and after sharing.

The glow opacity is controlled by:

```js
opacity: sending ? 0.9 : shared ? 0.6 : 0
```

You can increase or decrease these values to change the intensity.

For example:

```js
opacity: sending ? 1 : shared ? 0.8 : 0
```

---

## 16. DISABLE MULTIPLE CLICKS

The component prevents the share animation from starting again while it is already sending:

```js
if (sending) return;
```

The button is also disabled during the sending state:

```jsx
disabled={sending}
```

This prevents users from triggering multiple animations simultaneously.

---

## 17. CHANGE THE RESET TIME

After the share animation finishes, the component waits before removing the `Shared` state.

Current reset:

```js

  setShared(false);
}, 2800);
```

For a shorter success message:

```js
}, 2000);
```

For a longer success message:

```js
}, 4000);
```
