## 1. COMPONENT OVERVIEW

`HeartBurst` is an animated Like button built with:

* React
* Framer Motion
* Tailwind CSS

The component includes:

* Like / Unlike state
* Animated heart
* Like count
* Ripple effect
* Particle burst
* Floating mini hearts
* Heart glow
* Animated Like / Liked text
* Hover animation
* Tap animation

---

## 2. REQUIREMENTS

Install Framer Motion:

```bash
npm install framer-motion
```

Make sure Tailwind CSS is already configured in your React project.

---

## 3. FILE SETUP

Create a component file:

```text
src/
└── components/
    └── HeartBurst.jsx
```

Paste the `HeartBurst` component code into the file.

## 4. IMPORT THE COMPONENT

Inside your page:

```jsx

```

Then render it:

```jsx

```

Example:

```jsx
function App() {
  return (

    </div>

```

## 5. HOW THE LIKE BUTTON WORKS

The component uses two states:

```jsx
const [liked, setLiked] = useState(false);
const [count, setCount] = useState(124);
```

`liked` controls whether the button is liked.

`count` stores the current like count.

---

## 6. CHANGE DEFAULT LIKE COUNT

Find:

```jsx
const [count, setCount] = useState(124);
```

Change `124`:

```jsx

```

The component will start with:

```text
500
```

## 20. CHANGE PARTICLE COUNT

The particles are created from this array:

```jsx
[
  [-30, -28],
  [2, -40],
  [32, -25],
  [43, 4],
  [30, 31],
  [0, 39],
  [-34, 25],
  [-43, -2],
]
```

Each array item represents one particle.

Add another coordinate pair to create another particle:

```jsx
[55, 15],
```

---

## 21. CHANGE PARTICLE POSITION

Each particle uses:

```text
[x, y]
```

Example:

```jsx
[50, -30]
```

`x` controls horizontal movement.

`y` controls vertical movement.

Negative `y` moves upward.

Positive `y` moves downward.

## 39. CONNECT TO A REAL API

The current count is local React state.

For a real application, you can replace the local count logic with an API request.

Example:

```js
await fetch("/api/likes", {
  method: "POST",
});
```

Then update the count using the API response.

---

## 40. IMPORTANT

The current component does not connect to a backend.

The like count exists only in React state.

Refreshing the page resets the count to the initial value.

For permanent likes, connect the button to your backend/database.
