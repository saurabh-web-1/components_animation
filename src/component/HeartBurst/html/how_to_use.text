## 1. COMPONENT OVERVIEW

HeartBurst is an animated Like button built with:

* HTML
* CSS
* JavaScript

The component includes:

* Like / Unlike state
* Animated heart
* Like counter
* Ripple animation
* Particle burst
* Floating hearts
* Heart glow
* Text transition
* Counter animation
* Hover animation
* Mobile responsive styling

No external library is required.

---

## 2. FILE STRUCTURE

Create three files:

```text
HeartBurst/
├── index.html
├── style.css
└── script.js
```

---

## 3. CONNECT THE FILES

Inside `index.html`, include the CSS:

```html
<link rel="stylesheet" href="style.css">
```

At the bottom of the HTML:

```html
<script src="script.js"></script>
```

Make sure all three files are in the correct location.

---

## 4. HOW TO USE

Open `index.html` in your browser.

The button will appear in the center of the page.

Click the button to:

1. Change Like to Liked
2. Increase the count
3. Fill the heart
4. Start the ripple
5. Create particles
6. Show floating hearts
7. Show the heart glow

Click again to return to the Like state.

---

## 23. CHANGE PARTICLE DIRECTION

Each particle has its own position.

Example:

```css
.particle-1 {
  --x: -30px;
  --y: -28px;
}
```

`--x` controls horizontal movement.

`--y` controls vertical movement.

Negative `--y` moves upward.

Positive `--y` moves downward.

---

## 24. ADD MORE PARTICLES

## 39. JAVASCRIPT LIKE LOGIC

The current state starts with:

```js
let liked = false;
let count = 124;
```

When clicked:

```js
liked = !liked;
```

If liked:

```js
count++;
```

If unliked:

```js
count--;
```

The displayed count is updated using:

```js
likeCount.textContent = value;
```

---

## 40. IMPORTANT

This component uses local JavaScript state.

The like count is not stored in a database.

Refreshing the page resets the count.

For a real application, connect the click event to your backend/API to permanently store likes.
