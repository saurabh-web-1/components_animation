## 1. COMPONENT OVERVIEW

**MorphDrop** is an animated download button built with:

* HTML
* CSS
* Vanilla JavaScript
* SVG

Animation flow:

```text
Download
   ↓
Diamond Morph
   ↓
Loading Ring
   ↓
Success
   ↓
Open
```

## 3. COMPONENT STATES

JavaScript uses:

```js
let status = "idle";
```

Available states:

```text
idle
morphing
loading
complete
```

The state is applied as a class to the button.

## 10. MORPH DIAMOND

Diamond color:

```css
.morph-diamond {
  color: #fcd34d;
}
```

Initial state:

```css
opacity: 0;
transform:
  translateY(-50%)
  scale(.7)
  rotate(-45deg);
```

The diamond becomes visible during the `morphing` state.

---

## 11. DIAMOND ANIMATION

Animation:

```css
animation:
  diamondMove
  .85s
  cubic-bezier(.22,1,.36,1)
  forwards;
```

The movement is controlled by:

```css
@keyframes diamondMove
```

Main scale:

```css
65% {
  transform:
    translateY(-50%)
    scale(1.15)
    rotate(0deg);
}
```

Change `1.15` for a stronger or softer pop.

## 12. MORPHING TIMING

JavaScript changes to loading after:


## 16. LOADING DURATION

Loading starts with:

```js
loadingTimer = setTimeout(
  function () {
    setStatus("complete");
  },
  2300
);
```

Current duration:

```text
2300ms
```

The CSS progress animation also uses:

```css
animation:
  progress
  2.3s
  ease-in-out
  forwards;
```

Keep both durations synchronized.

---

## 17. PROGRESS RING

## 19. CHECK DRAWING

The check path uses:

```css

  stroke-dasharray: 30;
  stroke-dashoffset: 30;
}
```

Animation:

```css
@keyframes checkDraw {
  from {
    stroke-dashoffset: 30;
  }

  to {
    stroke-dashoffset: 0;
  }
}
```

Change `.4s` to control the drawing speed.

## 21. STATE FLOW

Button click when idle:

```js
if (status === "idle") {
  setStatus("morphing");
}
```

Then:

```text
idle → morphing
```

After `850ms`:

```text
morphing → loading
```

After `2300ms`:

```text
loading → complete
```

---

## 22. RESET TO IDLE

Clicking the completed button runs:

```js
else if (status === "complete") {
  clearTimeout(morphTimer);
  clearTimeout(loadingTimer);
  setStatus("idle");
}
```

This restores the Download state.

## 26. IMPORTANT

This component is a **UI animation demo**.

The current JavaScript does not download an actual file. It uses timers to simulate:

```text
Download → Loading → Complete
```

For production, replace the `setTimeout()` loading logic with your real file/API download process.
