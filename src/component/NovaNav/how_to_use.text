## 1. COMPONENT OVERVIEW

`NovaNav` is a responsive bottom-style navigation component built with:

- React
- Tailwind CSS
- Lucide React

The component includes:

- 5 navigation items
- Active navigation state
- Animated active pill
- Lucide icons
- Notification indicator
- Hover animation
- Active icon animation
- Responsive width
- Dark navigation design

---

## 2. REQUIREMENTS

Install Lucide React:

```bash
npm install lucide-react
```

Make sure Tailwind CSS is configured in your React project.

---

## 3. FILE STRUCTURE

Create:

```text
src/
└── components/
    └── NovaNav/
        └── NovaNav.jsx
```

Paste the component code inside `NovaNav.jsx`.

---

## 4. HOW TO USE

Import the component:

```jsx
import NovaNav from "./components/NovaNav/NovaNav";
```

Render it:

```jsx
<NovaNav />
```

Example:

```jsx
function App() {
  return (
    <main className="min-h-screen flex items-center justify-center">
      <NovaNav />
    </main>
  );
}

export default App;
```

---

## 5. ACTIVE NAVIGATION

The active item is controlled by:

```jsx
const [active, setActive] = useState("Home");
```

The default active item is:

```text
Home
```

To start with Search:

```jsx
const [active, setActive] = useState("Search");
```

---

## 6. CHANGE NAVIGATION ITEMS

Items are stored inside:

```jsx
const items = [
  {
    name: "Home",
    icon: Home,
  },
];
```

Add a new item:

```jsx
{
  name: "Profile",
  icon: UserRound,
}
```

The component will automatically render it.

---

## 7. REMOVE AN ITEM

Simply remove its object from the `items` array.

Example:

```jsx
{
  name: "Saved",
  icon: UserRound,
}
```

Delete that object to remove Saved from the navigation.

## 35. CHANGE NAVIGATION POSITION

The component itself does not use fixed positioning.

To make it fixed at the bottom:

```jsx
<main className="min-h-screen flex items-end justify-center pb-6">
  <NovaNav />
</main>
```

For a fixed bottom navigation:

```jsx
<nav className="fixed bottom-6 left-1/2 -translate-x-1/2">
```

Use the existing navigation classes together with these positioning classes.

## 36. CHANGE ITEMS THROUGH DATA

You can easily create your own navigation:

```jsx
const items = [
  {
    name: "Dashboard",
    icon: Home,
  },
  {
    name: "Explore",
    icon: Search,
  },
  {
    name: "Create",
    icon: Plus,
  },
  {
    name: "Messages",
    icon: MessageCircle,
    notification: true,
  },
  {
    name: "Profile",
    icon: UserRound,
  },
];
```

No changes are required to the `.map()` logic.

## 37. ADD CLICK ACTIONS

Currently clicking an item only changes:

```jsx
setActive(item.name)
```

For real navigation, you can add routing logic inside:

```jsx
onClick={() => {
  setActive(item.name);
}}
```

For example, React Router can be used to navigate to different pages.

## 38. ACTIVE PILL ANIMATION

The component includes a custom CSS animation:

```css
@keyframes navWave
```

The animation uses:

```css
scaleX(0.2)
scaleX(1.5)
scaleX(1)
```

This creates the expanding navigation effect.

## 40. IMPORTANT

The current component manages the active item only with React state.

It does not automatically change pages or routes.

To connect it with your application pages, add your own navigation or React Router logic.
