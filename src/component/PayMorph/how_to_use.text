# PayMorph — How to Use

PayMorph is a React payment-card UI built with **React, Tailwind CSS, and Framer Motion**.

It includes:

* Live card preview
* Card number formatting
* Card brand detection
* Card flip animation
* CVV interaction
* Expiry formatting
* Payment validation
* Processing animation
* Success animation
* Success particles

---

## 1. Requirements

Install Framer Motion:

```bash
npm install framer-motion
```

Make sure Tailwind CSS is configured in your React project.

---

## 2. Component Setup

Create:

```text
src/
└── components/
    └── PayMorph.jsx
```

Paste the PayMorph component code into `PayMorph.jsx`.

---

## 3. Import Component

```jsx
import PayMorph from "./components/PayMorph";
```

Then render:

```jsx
<PayMorph />
```

Example:

```jsx
export default function App() {
  return (
    <main className="min-h-screen bg-[#07090d]">
      <PayMorph />
    </main>
  );
}
```

# CUSTOMIZATION

## 4. Change Payment Amount

Find:

```jsx
Pay ₹2,499
```

Change it to:

```jsx
Pay ₹4,999
```

or:

```jsx
Pay $99
```

This changes the amount displayed on the payment button.

Note: this component does not process a real payment.

---

## 5. Change Card Background

The front card uses:

```jsx
bg-gradient-to-br
from-[#20252f]
via-[#11151d]
to-[#080a0f]
```

Change these colors to customize the card.

Example:

```jsx
bg-gradient-to-br
from-purple-900
via-slate-900
to-black
```

You can create your own gradient using any Tailwind colors.

## 14. Change Card Holder Format

The holder is automatically converted to uppercase:

```jsx
setHolder(
  e.target.value.toUpperCase()
)
```

If you want to preserve the user's original capitalization, use:

```jsx
setHolder(e.target.value)
```

---

## 15. Change Card Number Limit

The card number is limited to 16 digits:

```jsx
.slice(0, 16)
```

For a different maximum length, change the number.

Example:

```jsx
.slice(0, 19)
```

The current formatter adds a space after every four digits.

---

## 16. Change Expiry Format

The expiry formatter converts:

```text
1228
```

into:

```text
12/28
```

This behavior is controlled by:

```jsx
formatExpiry()
```

You can modify this function if your project requires a different date format.

## 17. Card Brand Detection

PayMorph currently detects:

```text
VISA
MASTERCARD
AMEX
CARD
```

Visa:

```jsx
/^4/
```

Mastercard:

```jsx
/^(5[1-5]|2[2-7])/
```

American Express:

```jsx
/^3[47]/
```

If no pattern matches, it returns:

```jsx
"CARD"
```

---

## 18. Add Another Card Brand

Card brands are detected inside:

```jsx
getCardBrand()
```

Add another condition before:

```jsx
return "CARD";
```

Example:

```jsx
if (/^6/.test(value)) {
  return "DISCOVER";
}
```

You would also need to add its visual design where the brand is rendered.

## 21. Change When Card Flips

The card flips to the back when CVV is focused:

```jsx
onFocus={() => setShowBack(true)}
```

It also flips when CVV contains a value.

When Card Number, Holder, or Expiry receives focus:

```jsx
setShowBack(false)
```

This keeps the front visible while editing those fields.

---

## 22. Change Validation

Payment validation checks:

```jsx
cardNumber.replace(/\s/g, "").length < 16
```

```jsx
holder.trim().length < 2
```

```jsx
expiry.length < 5
```

```jsx
cvv.length < 3
```

Change these conditions if your form requires different validation rules.

## 40. Important

PayMorph is currently a **frontend payment UI demonstration**.

The component does not connect to:

* Razorpay
* Stripe
* PayPal
* Any payment gateway
* Backend API
* Database

The `processing` and `success` states are simulated using `setTimeout`.

For a real payment system, connect the button to your backend/payment provider instead of treating the local success state as a completed transaction.
