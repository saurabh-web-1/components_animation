## 1. COMPONENT OVERVIEW

`Route404` is an interactive 404 page built with:

- React
- Tailwind CSS
- Framer Motion
- Lucide React

The page includes:

- Animated 404 screen
- Interactive plug and socket
- Drag-and-drop plug
- Magnetic socket detection
- Automatic plug insertion
- Connection animation
- Cable animation
- Connection flash
- Connect / disconnect button
- Responsive layout

---

## 2. REQUIREMENTS

Install the required packages:

```bash
npm install framer-motion lucide-react
```

Make sure Tailwind CSS is configured in your React project.

## 5. HOW THE COMPONENT WORKS

The plug can be dragged around the bottom stage.

When the plug comes close enough to the socket:

1. The socket detects the plug.
2. The plug moves toward the socket.
3. The pins slide inside.
4. The connection completes.
5. A connection flash appears.
6. The page changes to the connected state.

The plug can then be dragged away to disconnect.

---

## 6. CHANGE SNAP DISTANCE

Find:

```jsx
const SNAP_DISTANCE = 125;
```

This controls how close the plug must be to the socket.

Increase it:

```jsx
const SNAP_DISTANCE = 180;
```

The plug will connect from farther away.

Decrease it:

```jsx
const SNAP_DISTANCE = 80;
```

The plug must be closer to the socket.

- Position calculations

If you change the plug size significantly, update both `PLUG_BODY` and `PLUG_TOTAL`.

## 9. CHANGE INITIAL PLUG POSITION

The initial position is calculated here:

```jsx
const disconnectedPlug = {
  x: Math.max(70, width * 0.22),
  y: groundY - PLUG_BODY.height + 2,
};
```

Change:

```jsx
width * 0.22
```

to move the plug horizontally.

Example:

```jsx
width * 0.30
```

moves the plug farther right.

---

## 10. CHANGE SOCKET POSITION

The socket position is calculated using:

```jsx
const socket = {
  x: width - Math.max(92, width * 0.065),
  y: height * 0.53,
};
```

Change `0.53` to move the socket vertically.

Example:

```jsx
y: height * 0.60
```

moves it lower.

---

## 11. CHANGE CONNECTED PLUG POSITION

The connected position is:

```jsx
const connectedPlug = {
  x: socketOpeningLeft - PLUG_BODY.width + 8,
  y: socket.y - PLUG_BODY.height / 2,
};
```

Change `+ 8` to adjust how far the plug sits inside the socket.

---

## 12. CHANGE PRE-INSERT POSITION

The pre-insert position is:

```jsx
const preInsertPlug = {
  x: connectedPlug.x - 22,
  y: connectedPlug.y,
};
```

Change `- 22` to control the distance before insertion.

Example:

```jsx
x: connectedPlug.x - 35
```

---

## 13. CHANGE CONNECTION TIMING

The connection currently has multiple phases.

First phase:

```jsx
setTimeout(() => {
  setInserting(true);
}, 430);
```

Second phase:

```jsx
setTimeout(() => {
  setConnected(true);
}, 420);
```

Increase these values for a slower connection.

Decrease them for a faster connection.

## 38. RESPONSIVE DESIGN

The component calculates its geometry from:

```jsx
stageRef.current.getBoundingClientRect()
```

and updates it when the window resizes.

This allows the plug, socket, and cable to adapt to different screen sizes.
