ANIMATED SEARCH — COMPONENT GUIDE


Component: ScanPulse
Type: React + Tailwind CSS + Framer Motion
File: ScanPulse.jsx





1. REQUIREMENTS

Make sure your React project has Tailwind CSS and Framer Motion installed.

npm install tailwindcss @tailwindcss/vite
npm install framer-motion

The component uses React hooks:
- useState
- useRef
- useEffect


2. ADD THE COMPONENT TO YOUR PROJECT

Create a file such as:

src/components/ScanPulse.jsx

Paste the downloaded component code into that file.


3. IMPORT THE COMPONENT
-----------------------
In the page where you want to use it:

import ScanPulse from "./components/ScanPulse";

If your folder structure is different, change the import path.


4. USE THE COMPONENT
--------------------
Then render it like this:

function App() {
  return (
    <div>
      <ScanPulse />
    </div>
  );
}

export default App;


5. HOW THE SEARCH WORKS
-----------------------
The component has three main states:

idle
- Normal search state.
- Button shows "Search".
- User can enter text and search.

searching
- Starts after submitting the form.
- Input is disabled.
- Button shows "Searching".
- Search icon animates.
- Search box pulses.
- Scanning line moves across the bottom.

success
- After the demo search finishes.
- Button changes to "Done ✓".
- Search icon changes to a check mark.
- Result card appears.
- User can click "Search again" to reset.

The state is controlled with:

const [status, setStatus] = useState("idle");


6. CONNECT IT TO A REAL API
----------------------------
Currently the component uses:

setTimeout(() => {
  setStatus("success");
}, 1400);

This only simulates a search.

For a real project, replace the demo timeout with your API request.

Example:

const handleSearch = async (e) => {
  e.preventDefault();

  if (!query.trim() || status === "searching") {
    return;
  }

  setStatus("searching");

  try {
    const response = await fetch(
      `/api/search?q=${encodeURIComponent(query)}`
    );

    if (!response.ok) {
      throw new Error("Search failed");
    }

    const data = await response.json();

    // Store/use your search results here
    console.log(data);

    setStatus("success");
  } catch (error) {
    console.error(error);
    setStatus("idle");
  }
};

This allows the animation to represent an actual API search.

{results.map((item) => (

const [results, setResults] = useState([]);

---------------------------
The demo currently waits 1400 milliseconds.

12. MAKE THE COMPONENT SMALLER / SHORTER
----------------------------------------
If you want a simpler version, you can remove:

- Heading and description
- Success result card
- "Search again" button
- Scanning line
- Some icon animations
- Demo timeout cleanup logic

For a basic search component, keep only:

1. query state
2. status state
3. handleSearch
4. input
5. submit button

Example structure:

const [query, setQuery] = useState("");

const handleSearch = (e) => {
  e.preventDefault();

  if (!query.trim()) return;

  console.log("Searching:", query);
};

return (
  <form onSubmit={handleSearch}>
    <input
      value={query}
      onChange={(e) => setQuery(e.target.value)}
      placeholder="Search..."
    />

    <button type="submit">
      Search
    </button>
  </form>
);


13. IMPORTANT CUSTOMIZATION
---------------------------
