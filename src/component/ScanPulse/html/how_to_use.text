## 1. COMPONENT OVERVIEW

`ScanPulse` is an animated search component built with:

* HTML
* CSS
* JavaScript

It includes:

* Animated search box
* Search icon animation
* Loading spinner
* Scanning line
* Success animation
* Result card
* Search again button
* Responsive mobile layout

The JavaScript uses three states:

```js
idle
searching
success
```

## 6. CHANGE SEARCH DELAY

The demo currently waits `1400ms` before completing the search:

```js
searchTimeout = setTimeout(
  function () {
    completeSearch(query);
  },
  1400
);
```

For faster testing:

```js
500
```

For slower animation:

```js
2000
```

This is only a simulated API delay.

---

## 7. CONNECT REAL SEARCH API

Currently the component uses:

```js
setTimeout(...)
```

instead of a real API.

Replace the simulated search with your API request.

Example structure:

```js
async function searchAPI(query) {
  const response = await fetch(
    `/api/search?q=${encodeURIComponent(query)}`
  );

  return response.json();
}
```

Then call your API before:

```js
completeSearch(query);
```

The current code does not contain a real backend/API.

---

## 8. SEARCH VALIDATION

Empty searches are prevented here:

```js
const query =
  searchInput.value.trim();

if (!query) {
  return;
}
```

You can replace this with an error message if required.

## 9. SEARCHING ANIMATION

When searching starts:

```js
searchBox.classList.add("searching");
iconWrapper.classList.add("icon-searching");
```

The search box uses:

```css
.searching {
  animation:
    searchPulse 0.5s ease-in-out infinite;
}
```

The search icon uses:

```css
.icon-searching {
  animation:
    iconSearch 0.7s ease-in-out infinite;
}
```

---

## 10. CHANGE SEARCH BOX ANIMATION

Find:

```css
@keyframes searchPulse
```

Current scale:

```css
50% {
  transform: scale(1.012);
}
```

Increase `1.012` for a stronger pulse.

Example:

```css
transform: scale(1.03);
```

---

## 11. CHANGE ICON ANIMATION

Find:

```css
@keyframes iconSearch
```

The animation moves and rotates the search icon.

Important values:

```css
translateX(4px)
rotate(12deg)
rotate(-12deg)
```

Change these values to adjust the icon movement.

When search completes:

```js

```

```css
@keyframes successPop
```

It starts with:



## 19. SEARCH AGAIN

The button:

```html
<button
  id="searchAgain"
  class="search-again"
>
  Search again
</button>
```

resets:

* Search status
* Input
* Button text
* Search icon
* Success icon
* Result card

Then it focuses the input:

```js
searchInput.focus();
```

---

## 20. SEARCH STATE

The component uses:

```js
let status = "idle";
```

During search:

```js
status = "searching";
```

After completion:

```js
status = "success";
```

This prevents multiple searches while one search is running.

## 24. CURRENT LIMITATION

The current search is a frontend demo.

It does not include:

* Real search API
* Database
* Search results from backend
* Authentication
* Search history

You need to connect your own API/backend for real search functionality.
