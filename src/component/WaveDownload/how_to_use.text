## 1. COMPONENT OVERVIEW

**WaveDownload** is an animated download button built with:

* React
* Tailwind CSS
* Framer Motion
* SVG

The component includes:

* Download icon
* Morphing horizontal line
* Animated loading wave
* Loading dots
* Success check animation
* Failure X animation
* Success/failure status text
* Button color transition
* Failure shake/morph effect
* Disabled state during download

---

## 2. IMPORTS

```jsx
import { useState } from "react";
import { motion, AnimatePresence } from "framer-motion";
```

Install Framer Motion if required:

```bash
npm install framer-motion
```

---

## 3. COMPONENT STATE

The component uses:

```jsx
const [status, setStatus] = useState("idle");
```

Available states:

```text
idle
morphing
loading
success
fail
```

Each state controls a different visual stage.

## 4. DOWNLOAD FLOW

When the button is clicked:

```jsx
startDownload()
```

The animation follows:

```text
Download Icon
      ↓
Horizontal Line
      ↓
Loading Wave
      ↓
Success / Failure
```

The initial morphing state starts here:

```jsx
setStatus("morphing");
```

## 6. CHANGE BUTTON COLOR

The default button color is:

```jsx
"#0891b2"
```

It is used here:

```jsx
backgroundColor:
  status === "success"
    ? "#0891b2"
    : "#0891b2"
```

Replace `#0891b2` with your preferred color.

Example:

```jsx
"#6366f1"
```

## 10. DOWNLOAD ICON

The initial icon appears only when:

```jsx

```

```jsx
height="42"
```

## 11. DOWNLOAD ICON ANIMATION

The icon enters with:

```jsx
initial={{
  opacity: 0,
  scale: 0.5,
}}
```

and becomes:

```jsx
animate={{
  opacity: 1,
  scale: 1,
}}
```

It exits with:

```jsx
exit={{
  opacity: 0,
  scale: 0.4,
  rotate: 90,
}}
```

Modify these values to change the icon transition.

## 12. HORIZONTAL LINE

After clicking the button:

```jsx
setStatus("morphing");
```

The download icon is replaced by a horizontal line.

Current width:

```jsx
width: 34
```

Animation starts from:

```jsx
width: 0,
opacity: 0,
```

and ends at:

```jsx
width: 34,
opacity: 1,
```

Change `34` for a longer or shorter line.

---

## 13. MORPHING TIMING

The line appears first, then loading starts after:

```jsx
setTimeout(() => {
  setStatus("loading");
}, 700);
```

Current delay:

```text
700ms
```

Increase it for a longer line stage.

## 15. WAVE ANIMATION

The main wave continuously changes between two SVG paths.

Animation:

```jsx
duration: 0.8,
repeat: Infinity,
ease: "easeInOut",
```

Change `0.8` to control wave speed.

Example:

```jsx
duration: 0.5
```

makes the wave faster.

## 19. SUCCESS / FAILURE RESULT

The component currently uses:

```jsx
const success = Math.random() > 0.35;
```

This means the demo uses approximately:

```text
65% success
35% failure
```

```jsx

```

For always-failure:


## 28. CONNECT REAL DOWNLOAD

Currently the component only simulates a download.

The demo result is generated using:

```jsx
Math.random()
```

For a real download, replace the result logic inside:

```jsx
setTimeout(() => {
  ...
}, 3200);
```

with your actual download/API logic.

Example flow:

```text
Start Download
      ↓
Set loading
      ↓
Request file/API
      ↓
Success → success
      ↓
Error → fail
```

---

## 29. PREVENT MULTIPLE CLICKS

The button is disabled whenever:

```jsx
status !== "idle"
```

This prevents starting another download while the current animation is running.
