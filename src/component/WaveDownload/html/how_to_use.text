## 1. COMPONENT OVERVIEW

**WaveDownload** is an animated download button built with:

* HTML
* CSS
* Vanilla JavaScript
* SVG

Animation flow:

```text
Download Icon
      ↓
Horizontal Line
      ↓
Wave Loader
      ↓
Success / Failure
```

The JavaScript controls the complete state flow.

---

## 2. FILE STRUCTURE

Recommended structure:

```text
WaveDownload/
├── index.html
├── style.css
└── script.js
```

HTML loads:

```html
<link rel="stylesheet" href="style.css" />
```

and:

```html
<script src="script.js"></script>
```

## 3. COMPONENT STATES

The component uses:

```js
let status = "idle";
```

Main states:

```text
idle
morphing
loading
success
fail
```

Each state controls a different animation stage.

## 9. DOWNLOAD ICON ANIMATION

Active state:

```css
.download-icon.active {
  opacity: 1;
  transform:
    translate(-50%, -50%)
    scale(1);
}
```

Exit state:

```css
.download-icon.leaving {
  opacity: 0;
  transform:
    translate(-50%, -50%)
    scale(0.4)
    rotate(90deg);
}
```

Change `scale()` and `rotate()` to customize the exit animation.

## 10. MORPHING LINE

The horizontal line starts with:

```css
.morph-line {
  width: 0;
  height: 3px;
  opacity: 0;
}
```

Final width:

```css
@keyframes lineMorph {
  100% {
    width: 34px;
    opacity: 1;
  }
}
```

Change `34px` to make the line longer or shorter.

## 19. SUCCESS / FAILURE PROBABILITY

The result is currently generated with:

```js
const success =
  Math.random() > 0.35;
```

This produces approximately:

```text
65% success
35% failure
```

For always-success:

```js
const success = true;
```

For always-failure:

```js
const success = false;
```

## 28. RESET TO IDLE

The component uses:

```js
function setIdle() {
  status = "idle";

  hideAll();

  downloadIcon.classList.add("active");
}
```

This restores the initial download icon and removes other states.

---

## 29. SUCCESS CLICK BEHAVIOR

When the button is in the success state:

```js
if (status === "success") {
  setIdle();
  return;
}
```

Clicking the button after success resets it to the download state.

---

## 30. PREVENT MULTIPLE DOWNLOADS

The download function checks:

```js
if (status !== "idle") {
  return;
}
```

This prevents the user from starting another animation while the current process is running.
